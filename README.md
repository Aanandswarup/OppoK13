# OPPO K13 Gaming Landing Page

Marketing landing page for the OPPO K13 gaming phone. React + Tailwind, ships as a single HTML file.

## Run

```sh
npm install
npm run dev      # http://localhost:5173
npm run build    # single-file dist output
```

## Live

Deployed with GitHub Pages from `main` — see the repo's Deployments.

## Tech

React 19, Vite 7, Tailwind CSS 4, `vite-plugin-singlefile`.
